# ЛР2 «Табулирование функций» (вариант 3)

Программа на C++ в Docker. Табулирует функции F(x) = sin x + cos x - 1 и G(x) = (x + 5)^3 / (1 + sin^2 x) на отрезке [A; B] с N интервалами.

Нужен только установленный и **запущенный** Docker (на Windows и macOS это Docker Desktop). Работает одинаково в Linux, macOS, Windows (PowerShell и cmd).

## Запуск: две команды

Скопируй команды целиком (кнопка копирования справа в блоке) и вставляй в терминал по одной.

**1. Собрать образ** (прямо из GitHub, скачивать и распаковывать ничего не нужно):

```
docker build -t lab2 https://github.com/ЗАМЕНИ_НА_ЛОГИН/ЗАМЕНИ_НА_РЕПОЗИТОРИЙ.git
```

**2. Запустить программу:**

```
docker run -it --rm lab2
```

Дальше программа спросит A, B и N. Можно вводить обычные числа (0, 2.5, -1e3) и числа с pi (pi, -pi, 2pi).

## Без ручного ввода

Linux, macOS, Git Bash:

```
printf "0\npi\n10\n" | docker run -i --rm lab2
```

Windows PowerShell:

```
"0`npi`n10" | docker run -i --rm lab2
```

## Если первая команда не сработала

Сборка из ссылки требует установленного Git. Если его нет или команда выдала ошибку, скачай архив: на странице репозитория нажми зелёную кнопку **Code**, затем **Download ZIP**, распакуй, открой терминал в распакованной папке (там, где лежит `Dockerfile`) и выполни:

```
docker build -t lab2 .
docker run -it --rm lab2
```

Точка в конце первой команды обязательна. Файл `lab2-docker.zip` в репозитории содержит те же `Dockerfile` и `lab2.cpp`.

## Если русские буквы выглядят как «кракозябры»

В PowerShell или cmd перед запуском выполни:

```
chcp 65001
```

## Что внутри

- `lab2.cpp` - код программы.
- `Dockerfile` - сборка в два этапа: компилятор `gcc:13` собирает программу (статически, без внешних библиотек), а запускается она в маленьком образе `debian:bookworm-slim`.
